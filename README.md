# 🥤 HOLY SHOT!

Website resmi Holy Shot! — brand minuman sehat berbahan buah, sayur, rempah alami, dan minuman fermentasi Tepache.

Website ini berfungsi sebagai landing page interaktif yang menampilkan katalog produk, informasi brand, testimoni pelanggan, serta sistem pemesanan berbasis WhatsApp.

---

## 🌐 Live Demo

https://your-holy-shot.vercel.app/

## 🔄 Alur Pemesanan

1. Pengunjung memilih produk.
2. Produk ditambahkan ke keranjang.
3. Pengunjung mengisi data pemesanan.
4. Sistem membuat ringkasan pesanan secara otomatis.
5. Pesanan dikirim ke WhatsApp admin.
6. Admin melakukan konfirmasi dan proses pre-order.

---

## 📝 Alur Ulasan

1. Pengunjung mengisi form ulasan.
2. Data dikirim menggunakan Google Apps Script.
3. Ulasan tersimpan ke Google Sheets.
4. Admin dapat melakukan moderasi langsung melalui Spreadsheet.
5. Ulasan yang disetujui ditampilkan pada website.
